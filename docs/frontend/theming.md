# Theming Strategy

**Purpose:** How Dark/Light/System theming is implemented and where theme-aware code should hook in.

**Scope:** Theme mechanism only. Component styling conventions belong to [ui-components.md](./ui-components.md).

**Related documents:** [ui-components.md](./ui-components.md), [state/zustand-strategy.md](../state/zustand-strategy.md), [decisions/0009-theme-strategy.md](../decisions/0009-theme-strategy.md)

**When to read:** Adding any component with theme-dependent styling, or touching the theme toggle.

**When to ignore:** Theme-agnostic business logic (services, schemas, non-visual hooks).

---

## Mechanism

- **`next-themes`** provides the `ThemeProvider`, mounted once in `src/app/layout.tsx`, supporting `"light" | "dark" | "system"`.
- This project uses Tailwind CSS v4, which configures theming in CSS rather than a `tailwind.config.ts` theme key. Dark mode is enabled via `@custom-variant dark (&:is(.dark *));` in `src/app/globals.css` (generated by the shadcn CLI); `next-themes` toggles the `dark` class on `<html>` exactly as it would under v3's `darkMode: 'class'` — the mechanism is the same, only where it's declared changed.
- shadcn/ui components are already theme-aware via CSS variables defined in `src/app/globals.css` (light and dark variable sets, declared under `@theme`) — no per-component dark-mode branching needed.

## Where the current theme lives

The user's _explicit selection_ ("light"/"dark"/"system") is read/written via `next-themes`' own hook (`useTheme`), not duplicated into a Zustand store — see [state/zustand-strategy.md](../state/zustand-strategy.md) for why Zustand is reserved for state next-themes doesn't already own (e.g. sidebar collapsed state lives in Zustand, theme does not).

## Adding a theme-aware component

Use Tailwind's `dark:` variant or shadcn's CSS variables (`bg-background`, `text-foreground`, etc.) — never branch component logic on `useTheme()`'s value unless the component needs to render genuinely different content (e.g. a logo swap), not just different colors.

Full rationale for next-themes over a hand-rolled context in [decisions/0009-theme-strategy.md](../decisions/0009-theme-strategy.md).
